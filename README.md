# LexiUp - Học Từ Vựng Tiếng Anh B1, B2, C1 (Chuẩn CEFR)

Ứng dụng web học từ vựng tiếng Anh tương tác lấy cảm hứng từ Memrise, được thiết kế chuyên biệt cho người Việt học từ vựng trình độ B1, B2 và C1 theo phương pháp **lặp lại ngắt quãng (Leitner System / SRS)**.

---

## 🌟 Điểm nổi bật
- **1 File HTML duy nhất (`index.html`)**: Chạy trực tiếp trên mọi trình duyệt web (Chrome, Edge, Safari, Firefox), không cần cài đặt Node.js hay dựng server.
- **Tích hợp sẵn 3,479 từ vựng Oxford B1–C1**:
  - **B1 • Trung cấp**: 791 từ
  - **B2 • Trung cao cấp**: 1,386 từ
  - **C1 • Cao cấp**: 1,302 từ
  - *Toàn bộ từ vựng đã được tích hợp mặc định trong code, không cần nạp thêm file nào!*
- **Sắp xếp khoa học & Tìm kiếm tức thì**: Phân loại theo các nhóm chủ đề thực tế, hỗ trợ lọc và sắp xếp A-Z.
- **Phát âm chuẩn Web Speech API**: Hỗ trợ chuyển đổi giọng Anh-Anh (UK) và Anh-Mỹ (US).
- **6 Dạng bài tập xoay vòng**: Trắc nghiệm nghĩa tiếng Việt, Trắc nghiệm định nghĩa tiếng Anh, Điền từ vào câu ví dụ (Cloze test), Nghe & gõ chính tả, Gõ lại từ theo nghĩa, Ghép cặp từ - nghĩa 4x4.
- **Đồng bộ tiến độ**: Xuất/nhập file sao lưu cá nhân (`.json`) để chuyển đổi thiết bị mà không mất Streak, XP hay Hộp Leitner.

---

## 🚀 Hướng dẫn đưa lên GitHub Pages (30 giây)

> 💡 **Quan trọng**: Bạn chỉ cần tải lên duy nhất file **`index.html`** lên kho GitHub của bạn (các file `.py` hoặc `.json` thô là công cụ tiền xử lý dữ liệu, không cần đưa lên).

1. Truy cập [GitHub](https://github.com) và tạo một Repository mới (ví dụ: `lexiup`).
2. Tải file **`index.html`** lên kho lưu trữ vừa tạo.
3. Vào mục **Settings** của repository -> Chọn **Pages** (ở cột bên trái).
4. Ở phần **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)` -> Nhấn **Save**.
5. Đợi khoảng 30 giây đến 1 phút, GitHub Pages sẽ tạo cho bạn đường link trực tiếp (dạng `https://<ten-user>.github.io/lexiup/`).
